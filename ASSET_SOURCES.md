# Visual asset sources

The following fan-site visuals are used by the portfolio:

- `source/images/nier/2b_wallpaper.jpg` — supplied from the local `Downloads/2b_wallpaper.jpg` file and sampled into the site-wide ASCII background.
- `source/images/favicon-avatar.png` — Devarjya’s avatar, used only as the browser favicon and not displayed in the page layout.
- `themes/Quieter/source/fonts/league-gothic/` — League Gothic variable font and OFL license from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/leaguegothic), bundled locally for display headings.

The source wallpaper is never displayed directly in the page layout. NieR:Automata and its characters are © SQUARE ENIX CO., LTD. Copyright is not transferred with this repository.
